# Color Palette

## Brand colors

| Token | HEX | Usage |
|---|---|---|
| primary | #166534 | Primary actions, brand |
| primary-hover | #14532D | Hover and active state |
| secondary | #15803D | Secondary brand accents |
| primary-soft | #DCFCE7 | Soft green backgrounds |

## Surfaces and text

| Token | HEX | Usage |
|---|---|---|
| page-bg | #F8FAFC | Main page background |
| surface | #FFFFFF | Cards, forms, panels |
| text-primary | #0F172A | Main text |
| text-secondary | #64748B | Supporting text |
| border | #E2E8F0 | Dividers and borders |

## Semantic colors
- Success: #15803D
- Warning: #B45309
- Danger: #B91C1C
- Info: #1D4ED8

## Rules
- Maintain readable text/background contrast.
- Do not communicate status by color alone.
- Use primary green sparingly for hierarchy.
- Prefer neutral surfaces for dense financial screens.
- Verify contrast before introducing new shades.
